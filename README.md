## Sobre o jogo

Jogo da Velha (3x3) para **dois jogadores humanos**, feito em Python e executado no terminal.
O tabuleiro é uma matriz (lista de listas), percorrida com laços `for` aninhados.

### Desafios escolhidos

- **Campeonato melhor de 3 ou 5:** vence quem chegar primeiro ao número de vitórias necessário.
- **Estatísticas da sessão:** resumo das partidas jogadas durante a execução.
